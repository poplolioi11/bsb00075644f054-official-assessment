# 革員病瘋（《點石齋畫報》甲六第47圖，1884 年，巴伐利亞邦立圖書館） / Ge yuan bing feng [A Dismissed Official Assessed as Mentally Unwell]: Transcription Dataset

《點石齋畫報》甲六〈革員病瘋〉記一位被革職的候補知縣到文廟門前，地方官因其形跡可疑而命人搜問。記事保存當事人的自述及讞局詢問，並記上官裁定以瘋患方式處理。報刊所載的司法判斷可與同時代家屬或醫者的紀錄對照。MIT 已公開耶魯藏本的中文錄文和英譯。本資料依巴伐利亞藏圖保存原欄、圖中題字、印款和可定位疑讀。

The Dianshizhai Pictorial report follows a dismissed county magistrate candidate who appeared outside a Confucian temple. It recounts the authorities’ inquiry, the man’s own account, and the decision to handle him as someone considered mentally unwell. The report documents a published example of official assessment outside a hospital. MIT already presents a Chinese reading and English translation from the Yale copy. This dataset preserves the Bavarian witness's column divisions, labels, stamps, and located uncertainties.

## 方法與覆核 / Methods and review

由 AI 依固定館方影像逐欄讀字，保留原字、版面與疑讀。原紀年依原刊印「甲六」。1884 年的判定依臺灣大學所藏王韜《淞隱漫錄》研究，該研究將同一原刊期標作 1884 年。原刊日未據此補定。　圖說正文、圖字、印與版記分列。人類全文雙校、專家審定、同儕審查及準確率量測尚未進行。實際模型識別與使用量未知。此資料公開供比對與引用，處理程式及影像另存。

An AI assistant transcribed the fixed source images column by column, preserving source forms, layout and uncertain readings. Text, caption, illustration labels, artist marks, seals, and page designations are described separately. Human proofreading, expert review, peer review and accuracy measurement are pending. The actual model identifiers and usage are unknown.
